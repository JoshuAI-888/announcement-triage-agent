# Milford brand language

## Core tokens

| Role | Value | Use |
|---|---:|---|
| Primary slate | `#303c42` | Navigation, headings, cover fields, primary text emphasis |
| Slate 2 | `#46545b` | Hover states and secondary dark surfaces |
| Muted slate | `#77858d` | Metadata, labels, supporting copy |
| Cloud | `#eef1f2` | Section and control backgrounds |
| Paper | `#ffffff` | Cards, tables, documents |
| Milford orange | `#e1690e` | Primary actions, master-brand emphasis, focus |
| KiwiSaver blue | `#1c99d6` | KiwiSaver classification and data |
| Investment Funds green | `#4bc864` | Investment Funds classification and data |
| Wealth purple | `#915fb4` | Wealth classification and data |

Use semantic colors sparingly: success `#198754`, warning `#f3a83b`, danger `#c94b42`.

## Typography

- Set display headings in Glypha Bold. Use it for page titles, report titles, large metrics, and short editorial statements.
- Set body, navigation, controls, labels, tables, and captions in Montserrat.
- Use sentence case. Avoid all-caps except short eyebrows and table headings.
- Keep body copy compact: 14–16 px in portals; 2.7–3.2 mm in A4 reports.
- Use tabular numerals for finance and performance columns.

## Shape and spacing

- Use 4 px control radii, 8 px card radii, and 14 px only for large contained surfaces.
- Use a 4 px base spacing rhythm. Common gaps: 8, 12, 16, 20, 24, 30, 40 px.
- Use fine cool-grey borders. Prefer hierarchy through space and type over heavy shadow.
- Keep cards white and practical. Do not use decorative gradients, glass effects, oversized pills, or SaaS-style neon treatments.

## Voice

Use direct, calm, evidence-led language. Label dates, periods, units, source status, ownership, and approval state. Avoid marketing superlatives in internal interfaces.

## Logo

Use the source SVG unmodified. On slate, apply a white treatment only through a CSS filter or use an approved white source asset. Keep clear space around the mark. Do not crop, recolor individual letters, add effects, or combine it with a new symbol.
